A web-based Sentiment Analysis application built using **Python, Flask, and NLTK (VADER)** that classifies user text as **Positive, Negative, or Neutral** in real time. The application provides an intuitive interface for analyzing opinions, reviews, and feedback using Natural Language Processing (NLP).

### Features
- Real-time sentiment analysis
- Positive, Negative, and Neutral classification
- Flask-based REST backend
- Responsive and user-friendly interface
- Deployed on Render for public access

### Tech Stack
- Python
- Flask
- NLTK (VADER Sentiment Analyzer)
- HTML, CSS, JavaScript
